# Practical 13: Flexbox Layouts

## Aim:
To learn and implement CSS Flexbox for creating flexible webpage layouts.

## Introduction:
Flexbox is a CSS layout model used to arrange elements in rows or columns.

## Theory:
Flexbox makes it easier to align and distribute space between items inside a container.

Important Flexbox properties:

- `display: flex` – Enables Flexbox.
- `flex-direction` – Sets the direction of items.
- `justify-content` – Aligns items horizontally.
- `align-items` – Aligns items vertically.
- `flex-wrap` – Allows items to move to the next line.
- `gap` – Adds space between items.

## Procedure:
1. Create an HTML file.
2. Create a Flexbox container.
3. Add multiple items inside it.
4. Apply Flexbox properties using CSS.
5. Run the webpage in a browser.

## Result:
Successfully created a flexible webpage layout using CSS Flexbox.
