Aim:
To learn CSS units and variables and use them in webpage styling.

Introduction:
CSS units are used to define sizes, spacing and dimensions of HTML elements. CSS variables help store reusable values.

Theory:
CSS Units:
Some commonly used CSS units are:
px: Defines size in pixels.
%: Defines size relative to the parent element.
em: Relative to the font size of the parent element.
rem: Relative to the root font size.
vw: Relative to the viewport width.
vh: Relative to the viewport height.

CSS Variables:
CSS variables store reusable values and are declared using -- before their names. They are accessed using the var() function.

Procedure:
Create an HTML file.
Define CSS variables inside :root.
Use variables for colors and spacing.
Apply different CSS units to elements.
Run the file in a browser.

Result:
Successfully used different CSS units and variables in an HTML webpage.
