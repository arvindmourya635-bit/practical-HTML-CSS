Aim:
To create an HTML table using headers, body and footer sections.

Introduction:
HTML tables are used to display data in rows and columns.

Theory:
HTML provides different tags to create tables:
<table>: Defines a table.
<thead>: Groups the header content.
<tbody>: Groups the main table dat.
<tfoot>: Groups the footer content.
<tr>: Defines a table row.
<th>: Defines a header cell.
<td>: Defines a data cell.
These tags help organize tabular data clearly.

Procedure:
Create an HTML file.
Add a table using the <table> tag.
Create table headings using <thead> and <th>.
Add data using <tbody> and <td>.
Add a footer using <tfoot>.
Run the file in a browser.

Result:
Successfully created an HTML table with headers and footers.
