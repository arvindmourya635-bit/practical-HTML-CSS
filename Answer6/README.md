Aim:
To learn different types of lists in HTML.

Introduction:
HTML provides lists to display related information in an organized way.

Theory:
HTML supports three main types of lists:
Ordered List (<ol>): Displays items in a numbered order.
Unordered List (<ul>): Displays items using bullet points.
Description List (<dl>): Displays terms and their descriptions using <dt> and <dd> tags.
Lists make webpage content clear and well-organized.

Procedure:
Create an HTML file.
Use <ol> for an ordered list.
Use <ul> for an unordered list.
Use <dl> for a description list.
Run the file in a browser.

Result:
Successfully created a webpage using different types of HTML lists.
