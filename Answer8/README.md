Aim:
To create a sign-up form using HTML form elements.

Introduction:
HTML forms are used to collect information from users, such as name, email, password and choices.

Theory:
HTML provides different form elements:
<form>: Creates a form.
<input>: Accepts user input.
<label>: Defines a label for an input field.
<select>: Creates a dropdown list.
<option>: Defines options in a dropdown.
<input type="radio">: Allows users to select one option.
<input type="checkbox">: Allows users to select multiple options.
<button>: Creates a clickable button.

Procedure:
Create an HTML file.
Add name, email and password fields.
Add radio buttons and checkboxes.
Add a dropdown menu.
Add a submit button.
Run the file in a browser.

Result:
Successfully created a sign-up form using HTML form elements.
