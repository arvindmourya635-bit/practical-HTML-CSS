Aim:
To understand the CSS Box Model, create cards and apply scrolling effects.

Introduction:
The CSs Box Model describes how elements are displayed and spaced on a webpage.

Theory:

CSS Box Model:
Every HTML element consists of four parts:
Content: The actual text or image.
Padding: Space around the content.
Border: A line surrounding the padding.
Margin: Space outside the border.

Cards:
Cards are containers used to display information in a structured way. They can contain headings, images and paragraphs.

Scrolling:
CSS provides the overflow property to control content that exceeds an element's dimensions.
Common values are visible, hidden, scroll and auto.

Procedure:
Create an HTML file.
Apply padding, margin and border.
Create cards using HTML elements.
Apply scrolling using the overflow property.
Run the webpage in a browser.

Result:
Successfully created cards and applied CSS Box Model and scrolling properties.
