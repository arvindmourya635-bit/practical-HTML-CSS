Aim:
To learn how to add hyperlinks and images to an HTML webpage.

Introduction:
HTML provides tags to connect web pages and display images on a website.

Theory:
The <a> tag is used to create hyperlinks that connect one webpage to another. The href attribute specifies the destination URL.
The <img> tag is used to display images on a webpage. The src attribute specifies the image location, while the alt attribute provides alternative text.
Links and images make webpages more informative and interactive.

Procedure:
Create an HTML file.
Use the <a> tag to add a link.
Use the <img> tag to insert an image.
Set the required attributes.
Run the file in a browser.
Result:
Successfully created a webpage containing hyperlinks and images.
