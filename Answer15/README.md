# Practical 15: Responsive Pages with Media Queries

## Aim
To create a responsive webpage using CSS media queries.

## Introduction
Responsive web design makes a webpage adjust according to different screen sizes and devices.

## Theory
CSS Media Queries are used to apply different CSS styles based on screen size, width and device characteristics.

Important concepts:

- `@media` – Defines a media query.
- `max-width` – Applies styles when the screen width is below a specified value.
- `min-width` – Applies styles when the screen width is above a specified value.
- Responsive layouts – Adjust webpage elements for mobile, tablet and desktop screens.

## Procedure
1. Create an HTML file.
2. Add headings, paragraphs and content boxes.
3. Create a separate CSS file.
4. Apply normal CSS styling.
5. Use media queries to adjust the layout for smaller screens.
6. Run the webpage in a browser.

## Result
Successfully created a responsive webpage using CSS media queries.
