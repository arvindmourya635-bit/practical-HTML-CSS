Aim:
To learn the basic concepts of CSS and apply styling to an HTML webpage.

Introduction:
CSS stands for Cascading Style Sheets. It is used to control the appearance and layout of HTML elements.

Theory:
CSS is used to add colors, fonts, backgrounds, spacing and borders to HTML pages.
There are three types of CSS:
Inline CSS: Written inside the HTML element using the style attribute.
Internal CSS: Written inside the <style> tag in the HTML document.
External CSS: Written in a separate .css file and connected using the <link> tag.
CSS selectors are used to select HTML elements for styling.

Procedure:
Create an HTML file.
Add headings and paragraphs.
Apply CSS properties like color, background-color and font-size.
Save and run the file in a browser.

Result:
Successfully applied basic CSS styling to an HTML webpage.
