Aim:
To create a personal About Me webpage using HTML.

Introduction:
An About Me page provides basic information about a person, such as their name, education, hobbies and interests.

Theory:
HTML tags are used to organize personal information on a webpage.
<h1> is used for the main heading.
<h2> is used for subheadings.
<p> is used to write paragraphs.
<ul> and <li> are used to display hobbies and interests.
<img> is used to add a profile image.

Procedure:
Create an HTML file.
Add a heading with your name.
Write a short introduction.
Add education and hobbies.
Run the file in a browser.

Result:
Successfully created a personal About Me webpage using HTML.
